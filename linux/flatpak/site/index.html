Minimalistic Radio for Linux

A tiny internet radio that lives next to the clock. This is its Flatpak repository.

Install

Install Minimalistic Radio

The link opens in GNOME Software or Discover: click Install. Or run this in a terminal:

flatpak install https://zal3wa.github.io/minimalistic-radio/minimalistic-radio.flatpakref

On Ubuntu, enable Flatpak first: flathub.org/setup/Ubuntu.

Updates

Updates are automatic. They arrive through GNOME Software or Discover, or with flatpak update, and the radio shows a green arrow when a new version is ready.

Source code, the Windows version and how to report a problem: github.com/zal3wa/minimalistic-radio.
